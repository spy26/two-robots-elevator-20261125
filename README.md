## Run it

```sh
python3 main.py
```

This validates the one-line entry (a single line, 1–200 characters, no leading/trailing whitespace), writes it to `/output/entry.txt` (and to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), verifies each written file byte-for-byte against the entry, and prints the text to stdout.
